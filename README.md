# Ярлык расписания МГУУ — GitHub Pages

## Публикация
1. Войдите на github.com. Создайте новый Public репозиторий с названием mguu-schedule.
2. Распакуйте архив. Загрузите в корень репозитория всё содержимое папки, включая папку manifests. index.html должен находиться в корне, а не внутри дополнительной папки.
3. Нажмите Commit changes.
4. Откройте Settings → Pages. В Source выберите Deploy from a branch. Branch: main, Folder: / (root). Нажмите Save.
5. Дождитесь публикации. GitHub покажет адрес сайта в этом же разделе. Обычно он имеет вид https://ИМЯ.github.io/mguu-schedule/.

## Использование
Откройте опубликованную ссылку в Safari на iPhone или Chrome на Android. Выберите группу. Выбор сохраняется в настройке и адресе запуска ярлыка.
iPhone: Поделиться → На экран Домой. Оставьте Открывать как веб-приложение включённым, если переключатель показан.
Android: меню → Добавить на главный экран / Установить приложение.
После установки значок рассчитывает даты по московскому времени и открывает непосредственно портал МГУУ, от сегодняшнего дня до даты через 14 дней включительно.
Чтобы сменить группу, откройте ссылку настройки и переустановите ярлык.

## Ограничения
Интернет нужен для загрузки расписания. Доступность GitHub Pages без VPN зависит от сети и должна проверяться на телефонах пользователей. Установка и возобновление ярлыка на физических iPhone/Android ещё не проверены; браузер может восстановить ранее открытый портал вместо нового запуска. В этом случае закройте приложение и запустите значок заново.
В комплекте 66 групп бакалавриата, полученных с портала 13.10.2026. Новые группы нужно добавлять при изменениях на портале.
Сайт не добавляет дни недели внутрь портала и не запрашивает регистрацию у посетителей. Личные данные и выбранные группы не отправляются в отдельную базу.
