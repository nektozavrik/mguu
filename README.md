# mguu
В общем, это ссылка для открытия расписания на нашем сайте только в удобном формате. А именно дата текущего дня + 2 недели после. Это никак не меняет работу сайта. Сайт с расписанием работает так, что в ссылке, по которой вы открываете расписание строены даты "от" и "до" - интервал показа расписания. Он просто подставляет в "от" сегодняшнюю дату.
